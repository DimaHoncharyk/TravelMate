# 🌍 TravelMate — Your Personal Travel Assistant

**TravelMate** — вебзастосунок для планування персоналізованих подорожей, створення туристичних маршрутів, керування бюджетом та збереження цікавих місць.

Проєкт розроблено в межах дисципліни **«Основи дизайну UI/UX»**.

## 🚀 Live Demo

**Вебзастосунок:** https://travelmate-eight-inky.vercel.app/

## ✨ Основні можливості

- **Створення подорожей** — вибір міста, дат, бюджету, кількості мандрівників та інтересів.
- **Генерація маршрутів** — автоматичне формування плану подорожі з розподілом туристичних місць за днями.
- **Підтримувані міста** — Рим, Париж і Берлін.
- **Редагування маршрутів** — додавання та видалення туристичних місць.
- **Збережені місця** — формування власної колекції туристичних локацій.
- **Планування бюджету** — відображення орієнтовних витрат.
- **TravelMate Assistant** — демонстраційний чат-помічник із рекомендаціями щодо подорожей.
- **Локальне збереження** — дані зберігаються в браузері за допомогою localStorage.
- **Адаптивний дизайн** — підтримка мобільних пристроїв, планшетів і комп'ютерів.

## 💻 Локальний запуск

Для запуску потрібні Node.js 24 та npm.

**1. Клонування репозиторію**

```bash
git clone https://github.com/DimaHoncharyk/TravelMate.git
cd TravelMate
```

**2. Встановлення залежностей**

```bash
npm ci
```

**3. Запуск сервера розробки**

```bash
npm run dev
```

Застосунок буде доступний за адресою http://localhost:5173/.

**4. Production-збірка**

```bash
npm run build
```

**5. Запуск Storybook**

```bash
npm run storybook
```

Storybook буде доступний за адресою http://localhost:6006/.

## ⚠️ Обмеження

TravelMate є навчальним MVP. Генерація маршрутів працює на основі демонстраційних даних для трьох міст. Карта маршруту є схематичною, орієнтовні ціни не є актуальними тарифами, а чат-помічник використовує заздалегідь визначену логіку відповідей без інтеграції із зовнішньою AI-моделлю.
